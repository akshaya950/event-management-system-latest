About Our Project

Making event planning simple and organized.

About the System

The Event Management System is a simple web application designed to organize and manage events easily. Users can create events, view event details, update information, and delete events.

Our Purpose

The main purpose of this project is to reduce manual work and maintain event information in an organized way. It provides a simple and user-friendly interface.

Key Features

  • User Registration and Login
  • Dashboard for event management
  • Add and View Events
  • Edit Event Details
  • Delete Events

Technologies Used

Frontend: HTML and CSS
Backend: Python with FastAPI
Database: SQLite
