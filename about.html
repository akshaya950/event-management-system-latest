About the System

A clean, lightweight event management solution built for simplicity and efficiency.

🎯 Project Purpose

The Event Management System simplifies event coordination by replacing paperwork and messy spreadsheets with a streamlined digital platform.

👑 Role-Based Controls

Built with two dedicated user roles: Administrators with full control over event creation, scheduling, and attendee monitoring; and Attendees who can browse, register, and download verified certificates.

⚡ Technology Stack

Clean, minimal, hobby-focused stack without heavy third-party build tools:
• Frontend: Semantic HTML5, Custom CSS3, Vanilla JavaScript
• Backend: Python FastAPI
• Database: SQLite with SQLAlchemy
• Certificates: ReportLab PDF Generation

📜 Instant Certificates

Automatic generation of participation certificates formatted for official institutional presentation, complete with participant details and event names.
